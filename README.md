# Personal Data Science / ML Portfolio

A simple GitHub Pages portfolio built with plain HTML, CSS and JavaScript.

## Files

- `index.html` — page content and structure
- `style.css` — design and responsive layout
- `script.js` — small scroll-reveal animation

## What to replace

Search in `index.html` for:

- `YOUR NAME`
- `YOUR_EMAIL`
- `YOUR_GITHUB_URL`
- `YOUR_LINKEDIN_URL`
- `YOUR_PROJECT_URL_1`
- `YOUR_PROJECT_URL_2`
- `YOUR_PROJECT_URL_3`
- `YOUR_PROJECT_URL_4`
- `YOUR COMPANY`
- `YOUR DATES`
- `YOUR ACADEMY / COURSE`

You can also replace the placeholder project descriptions with your real GitHub projects.

## GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`, `style.css` and `script.js`.
3. Open repository Settings → Pages.
4. Select deployment from the `main` branch and `/root`.
5. Save and wait for GitHub Pages to publish the site.
