# Data Science & Machine Learning Portfolio

### Transforming Data into Business Value Through Analytics and Machine Learning

This portfolio showcases applied Data Science and Machine Learning projects focused on solving real-world business challenges and delivering measurable business value.

---

## 🚀 Featured Projects

### 🔍 **[Quora Question Pairs - Duplicate Question Detection](https://github.com/DiFedorchuk/Quora_Questions_Pairs)**
End-to-end NLP and Machine Learning project for identifying semantically duplicate questions using the Quora Question Pairs dataset.

Key highlights:

- Advanced NLP preprocessing and text representation
- Feature engineering and similarity analysis
- Machine Learning and Deep Learning models
- Transformer-based architectures (BERT)
- Production deployment with an interactive API

---

### 🏦 **[Bank Marketing Campaign Prediction](https://github.com/DiFedorchuk/Bank_Marketing_ML_Project)**
Machine Learning project that predicts whether a bank customer will subscribe to a term deposit.

Key highlights:

- End-to-end ML pipeline
- Hyperparameter optimization
- Explainable AI using SHAP
- Reproducible experimentation workflow
- Business-focused model evaluation

---

### 🌦️ **[Australian Rain Forecast](https://github.com/DiFedorchuk/Rain_Forecast)**
Predicting next-day rainfall in Australia using Machine Learning.

This project covers the complete Machine Learning lifecycle:

- Exploratory Data Analysis (EDA)
- Data preprocessing and feature engineering
- Model training and validation
- Performance evaluation
- Interactive Streamlit deployment
